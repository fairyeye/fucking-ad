## 🎯 项目初衷 (Manifesto)

你是否也经历过这些令人崩溃的瞬间？
- 走在路上刚掏出手机，手腕稍微一晃，立马触发 **「摇一摇 / 扭一扭」** 强行唤醒并跳转到某个购物或网贷软件；
- 弹窗上的关闭按键是伪装的假图标，或者小到只有几个像素，点上去直接触发全屏静默下载；
- 弹窗伪装成「微信红包到账」、「系统严重警告」或「好友发来未读消息」，专骗长辈和普通用户点击；
- 明明付了会员费，打开 APP 依然要被强制看 5 秒全屏广告。

很多人在心里暗下决心：*“这家公司的东西我一辈子都不买！”*  
但广告心理学就是利用了人类的**遗忘效应**：几个月后你忘了当初是在流氓弹窗里见过的它，只觉得这个品牌「很耳熟、知名度高」，于是在超市或网购时不自觉下了单——**流氓营销得逞了。**

**本项目旨在建立一份永久、公开、可查证的「流氓弹窗黑名单」**。
1. **记录在案**：把每次侵扰记录成代码，沉淀真实截图佐证，永久固定其恶行。
2. **消费避雷**：当你要购买某类商品或服务时，来这里搜一下，把钱投给真正尊重用户的良心品牌。
3. **反制工具**：提供干净软件替代品清单，帮助大家卸载作恶宿主 APP。
4. **社区共建**：人人的手机都是监控探头，让流氓投放无所遁形。

## 💡 良心替代品推荐库 (以良币驱逐劣币)

抵制劣质商业模式的最强武器，就是支持那些**干净、清爽、尊重用户**的产品与渠道：

### 1. 纯净宿主软件替代品（远离流氓弹窗）

- **替代【万年历】**：Simple Calendar (开源无广告)、手机系统自带日历 (无广告)
- **替代【优酷视频】**：Infuse / VLC / IINA (本地播放器)、无广告纯净流媒体
- **替代【墨迹天气】**：几何天气 (开源无广告天气)、和风天气精简版、系统自带天气
- **替代【酷狗音乐】**：Apple Music、Foobar2000、椒盐音乐 (开源无广告本地播放器)

### 2. 良心消费途径推荐（避开流氓投放商）

- **二手车/房产品类**：品牌官方认证二手车 / 线下正规4S店官方认证
- **电商购物品类**：品牌官方商城 / 京东自营 / 线下专柜直购
- **社交娱乐品类**：Bilibili (相对克制社区) / 优质播客客户端 (小宇宙)
- **金融借贷品类**：各大正规商业银行官方信贷渠道 (远离任何弹窗高利网贷)

## 🤝 如何参与贡献？

欢迎所有受害者共同维护这个黑名单！可以通过以下两种方式提交：

### 方式一：直接提 Issue 举报（推荐，免写代码）
1. 进入项目的 [Issues](../../issues/new?template=report_ad.yml) 页面；
2. 选择 **「举报流氓弹窗广告」** 模板；
3. 按照提示填写：广告品牌、宿主APP、截图凭证；
4. 维护者审核后会自动转化为数据并合入主分支。

### 方式二：提交 Pull Request（开发者通道）
1. Fork 本仓库并克隆到本地；
2. 将截图放入 `screenshots/YYYY/` 目录下；
3. 在 `data/records/` 下按照格式新增一条 `YYYYMMDD-品牌名-手法.yaml`；
4. 本地运行校验和编译：
   ```bash
   python3 scripts/lint_data.py
   python3 scripts/build_readme.py
   ```
5. 提交 PR，CI 会自动检查格式。

详细规范请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。

## ⚖️ 客观性与免责声明

1. **事实优先**：所有入库记录必须有真实截屏、录屏或网络公开报道等客观证据支撑，拒绝毫无根据的捏造与恶意中伤。
2. **就事论事**：记录针对的是「具体的流氓广告投放与诱导行为」，旨在维护消费者的知情权与选择权。
3. **改过即更新**：若某产品/品牌已全面下架整改此类流氓广告，可提交 Issue 并附上整改证据，项目将在记录中标记「已整改」并调整评级。
