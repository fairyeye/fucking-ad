## 🎯 项目初衷 (Manifesto)

你是否也经历过这些令人啼笑皆非的日常时刻？
- 走在路上刚掏出手机，手腕稍微一偏，手机陀螺仪便以迅雷不及掩耳之势判定为“扭动手机”，猝不及防为你推开电商百亿补贴的大门；
- 弹窗右上角的叉号仿佛是在视力表最后一行选拔出来的，尺寸微小且难以辨认，稍有不慎点偏半个像素，立即启动后台下载流水线；
- 红色横幅赫然写着“200,000元备用金即将失效”或仿冒微信未读红包，专挑防备心较低的长辈或注意力分散的用户下手；
- 明明充值了年度会员，打开 APP 依然要面对体贴的 5 秒开屏全屏推荐——关闭按钮甚至延迟 3 秒才慢条斯理地浮现。

不少人在被惊扰时暗下决心：*“这家公司的产品我坚决不用！”*  
然而，劣质营销恰恰利用了人类的**遗忘效应**：一段时间后，用户往往只记住了该品牌的“知名度与曝光量”，却遗忘了它曾粗暴打扰过自己的日常——**诱导投放由此达成了商业转化。**

**本项目旨在建立一份客观、公开、可查证的「移动端不良广告与诱导跳转留存名录」**：
1. **客观存证**：把每一次违规打扰记录成结构化数据，附带真实截图留存，让非体面的交互留下公开档案。
2. **理性避雷**：消费即投票。在日常消费与服务选购前搜一搜，把预算留给真正尊重用户的体面品牌。
3. **正向替代**：整理体面、清爽的开源与干净替代软件，协助大家逐步卸载肆意骚扰的宿主应用。
4. **社区共建**：汇聚广泛用户的真实日常样本，促使商业广告重新回归体面与克制。

## 🤝 如何参与贡献？

欢迎大家共同补充与维护这一名录！可以通过以下两种方式提交线索：

### 方式一：直接提 Issue 提交线索（推荐，免写代码）
1. 进入项目的 [Issues](../../issues/new?template=report_ad.yml) 页面；
2. 选择 **「提交流氓广告/诱导跳转案例」** 模板；
3. 按照提示填写：品牌名称、宿主APP、截图凭据；
4. 维护者审核后会自动转化为结构化数据并合入主分支。

### 方式二：提交 Pull Request（开发者通道）
1. Fork 本仓库并克隆到本地；
2. 将截图放入 `screenshots/YYYY/` 目录下；
3. 在 `data/records/` 下按照格式新增一条 `YYYYMMDD-品牌名-手法.yaml`；
4. 本地运行校验和编译：
   ```bash
   python3 scripts/lint_data.py
   python3 scripts/build_readme.py
   ```
5. 提交 PR，CI 会自动检查格式。

详细规范请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
